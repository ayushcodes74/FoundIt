# Findly — Campus Lost & Found

Findly is a campus-focused Lost & Found web application built using the MERN stack. It provides a common platform where students can report items they have lost and list items they have found on campus.

The platform organizes reports into separate Lost and Found sections, making it easier for students to discover missing belongings and help return them to their rightful owners.

## Planned Features

- Student registration and login
- Separate Lost Items and Found Items sections
- Create and view item listings
- Item details including name, description, location, date, and photo
- Search and filter listings
- Manage your own reports

## Tech Stack

- MongoDB — Database
- Express.js — Backend framework
- React.js — Frontend library
- Node.js — JavaScript runtime

## Project Goal

To build a practical, real-world MERN stack project while learning frontend development, REST APIs, backend logic, database integration, authentication, and deployment.

*This project is being developed incrementally, with additional features planned as the application evolves.*
